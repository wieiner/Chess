# Linux Server Package

P4B packages Linux deployment templates under `Deploy/linux` inside `ProductionOutput/ChessOnlineServer`.

Included:
- `chessonline-server.service.template`
- `nginx-chessonline.conf.template`
- `nginx-chessonline-https-snippet.template`

The package is intentionally marked as a scaffold because ChessOnlineServer is still a Windows-targeted build. Use these files for operational planning, not as proof of Linux runtime readiness.
