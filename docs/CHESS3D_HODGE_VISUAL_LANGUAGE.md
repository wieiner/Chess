# Chess3D Hodge Visual Language

Hodge Projection Duel visuals are enabled only for `hodge_projection_duel_3d_v0_1.json`.

- Macro-player groups are shown as side triads.
- Preview draws one primary arrow and two mirror arrows.
- Blocked mirrors use a red blocked path.
- Successful projected moves flash all three paths as one composite action.
- Failed projected moves leave board, state hash, reserve, and action history unchanged.

The arrows explain the composite move. They do not make rules; the engine validates transforms and all-or-nothing application.
