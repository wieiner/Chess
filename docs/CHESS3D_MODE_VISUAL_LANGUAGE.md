# Chess3D Mode Visual Language

P3C keeps the five real Chess3D RuleProfiles visually distinct without adding a sixth mode.

| Mode | Visual Language |
| --- | --- |
| Classic Six-Side | Normal board, legal/capture targets, current side, check/checkmate/stalemate status, checked king marker. |
| Single-Side Training | Clean training board, legal preview, sandbox/training text, king-safety smoke where applicable. |
| Asgard / Meru | CoreCube wash, stack badges, fusion rings, contested marker, anchors, reserve/knockback status. |
| Rubik Convergence | Asgard visuals plus explicit layer selector, selected layer wash, quarter-turn result text. |
| Hodge Projection Duel | Macro-player text, primary arrow, two mirror arrows, blocked mirror styling, all-or-nothing error text. |

Classic is not a hidden Asgard fallback. Asgard, Rubik, and Hodge stay profile-gated.
