# Chess3D Playability Known Issues

P2M improves visual assets, lighting, and click reliability, but these remain future work:

- No automated WPF click-through UI test yet.
- OBJ texture support is best-effort; full PBR/normal/roughness maps are deferred.
- Chess3D stack/fusion/reserve visuals are still status-panel based, not fully animated.
- Rubik layer turns execute instantly; animation is deferred.
- Hodge mirror paths are shown textually; richer overlays are deferred.
- Full Classic Six-Side king safety/check/mate/stalemate remains P3A.
- Save/load/replay/import/export remains P2N.
