# Chess3D Asgard Visual Language

Asgard/Meru visuals are enabled only when the active RuleProfile exposes center/core capabilities.

- CoreCube `x/y/z = 2..5`: translucent blue wash.
- Anchor target: warm smaller marker.
- Stack count: small gold bars on core cells with more than one stack entry.
- Friendly fusion: green ring.
- Royal pair: brighter gold ring.
- Contested/mixed cell: red marker.
- Implosion seed/ready descriptor: violet marker.
- Reserve/knockback: side panel text, not a drag/drop inventory in this stage.

The overlay is descriptive. Stack entries, fusion descriptors, anchors, and reserve counts still come from native ABI.
