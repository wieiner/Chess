# Asgard Online Playability Gate

P4B verifies that Asgard can pass through the online path:

1. two authenticated players join the Asgard queue;
2. matchmaking creates a room/table;
3. both players ready;
4. the server starts an authoritative Asgard snapshot;
5. a profile-legal Asgard action is accepted.

This is a server authority smoke gate. It is not a complete Asgard UX, ranked match, or cloud deployment.
